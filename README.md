# AutoDrawing 1.0.0：SolidWorks 3D 转 2D 自动标注

**1.0.0 齿轮公式与起端基准。** “齿轮公式…”支持原图已知尺寸、基准点坐标及来源标记，给出公式/条件/欠约束/冲突报告；直齿、内齿、斜齿、直锥、正交圆柱蜗杆副的参考几何已纳入计算。`calculate-gearing` 可脱离 SolidWorks 调用。当前长直齿条可从周期节距和主齿侧法向自动推算 m、α，标为“计算”，不吸附标准系列；图上增加关联实际端点的“起端 S (X=0)”及 X+方向，孔表使用同一基准，可选模型最小/最大端。起始角须有命名特征、零位基准、观察方向及正向，未确定不填 0°。蜗杆副当前仅为公式计算，尚未验证全自动制造标注。详见 [公式及边界](docs/gearing-formulas.md)。

**1.3.5 长直齿条专项出图。** 从成对、等距重复的平面齿侧识别长直齿条候选，跳过逐齿模型尺寸、全视图自动尺寸及齿部 C/R 泛化标注，采用 3 个外形尺寸、参数表和安装孔位表。细长主投影视图横向排布，轴测单独缩小并在表内标明比例。模数、压力角、分度线距背面等通过“齿条参数…”、模型属性或 `RackParameters` 提供，缺项显示待补，不从节距推算制造模数。孔表按实际同轴圆柱及原生倒角过渡核验贯通和沉孔范围，是生成时的测量快照，模型改动后需重新生成；齿形、公差、倒角及局部图需复核。示例：`examples/rack-job.json`。

**1.3.4 绕开导入圆锥倒角的挂起调用。** 对导入或来源不明的圆锥倒角，在读取任何视图轮廓前分流，保留原尺寸并列入 `SkippedChamfers`，继续圆角、去重和导出。只有来源类型与源特征记录均确认是原生 Chamfer 的圆锥倒角才进入轮廓投影路径；普通平面倒角仍按原流程处理。此版本不会自动引出导入圆锥倒角，需人工补标。报告增加 `ChamferSilhouetteScans`，每件进度日志写明实际版本、DLL 路径及进程。

**1.3.3 减少重复标注。** 默认“重复标注精简”（外部 `Deduplicate=true`）先保留模型已有尺寸，再按真实来源实体、模型轴向及参考点识别重复测量与无公差的自动闭合链；优先保留主视图关系。只修改本次自动生成的参考线性尺寸，无法证明的孔位/台阶尺寸不按同值删除。删除依据和仍保留的尺寸路径记录在 `RemovedRedundantDimensions`。同一视图、实体、来源及几何规格的自建恒定 R 圆角合为带数量的原生 R 标注，`RadiusCallouts.Quantity/MemberGeometries` 记录对应面；公差和作者尺寸保留。

**1.3.2 修复导入阀体倒角阶段异常。** 对供应商模型返回空曲线对象的轮廓边进行检查，圆锥/圆柱直线轮廓须经解析曲面与投影方向核验。倒角与圆角索引按视图复用，重建后失效；圆角需满足相切支撑条件。无法可靠标注的候选保留原尺寸并列出待补项。各阶段实时写入同名 `.progress.log`，不依赖窗口或控制台刷新。

**1.3.1 优化中途长时间无反馈。** 倒角识别只查询端点邻接边，避免对复杂轮廓重复扫描整张相邻面。几何/倒角扫描、视图线条读取、逐尺寸避让显示细分进度，界面在进度边界刷新。SolidWorks 操作仍在同一 STA 串行执行，不强行中断宿主 COM 调用；停止按钮在当前零件完成后停止后续任务。

**1.3.0 标注线避让、圆角 R 与齿轮专项出图。** 默认启用“标注线避让”：轮廓使用较粗黑线，尺寸和引线放入独立蓝色 `AUTO_DIMENSIONS` 图层，保持连续线型；按视图分配尺寸通道，检查实体线重合、尺寸线重合、交叉与文字碰撞，并依据同一来源实体单独识别共用尺寸界线。小图幅减少过度缩小视图。报告 `AnnotationLayout` 给出前后统计及重开后的结果；存在剩余冲突会提示复核，不能用“文字未碰撞”代替线条检查。图层颜色可在 SolidWorks 中自行更改。

默认“圆角 R 标注”支持可正视的恒定半径圆柱圆角/轮廓圆弧，使用关联实体的原生半径尺寸；对可证实的 90° 圆角，替换能由 R 和整体外形确定的自动辅助尺寸。报告 `RadiusCallouts` 核验半径、关联、重开及替换明细。变半径、自由曲面过渡、非正视圆弧需要局部图/剖视和人工复核，不强行当作一个固定 R。

齿轮模型可输出真实齿形投影、外形宽度、齿宽、轴孔及原生参数表，避免逐齿自动标注。模数、齿数等优先从模型配置/文档属性读取，也可在“齿轮参数…”中填写覆盖值或由外部 `Options.GearParameters` 指定；缺失压力角/精度等显示“未提供”，不从外径猜测。部分参数或文件提示加同轴复杂轮廓只能识别为 `gear_candidate`，会明确要求补参。通用投影适用于已有模型；齿轮专用修形、公差与检验设计仍需工程复核。外部调用示例见 `examples/gear-job.json`。

PDF 审查升级为默认启用；旧界面配置首次升级同步开启，此后保留明确保存的选择。运行根目录 `启动自动出图.cmd` 打开 1.0.0；旧窗口占用原目录时，版本目录仍可独立启动。

已验证恒定 R3 及正交放置的外啮合直齿轮样件；任意斜放模型、复杂曲面圆角和专用齿轮制造图需要补充法向视图/局部图/剖视。保存重开会重新读取尺寸及其关联；仅在模型文件状态、更新戳、配置和视图变换均一致时复用已检查的实体轮廓，报告记录 `GeometryReusedOnReopen`。

## 1.1 自动识别与流程

| 识别对象 | 依据和行为 |
|---|---|
| 通孔、平底盲孔 | 圆柱面、真实法向、完整角域、圆边轴向范围、底面面积；读取直径与圆柱段深度 |
| 外圆柱、轴件 | 区分实体外壁与内孔；读取外径和轴长，长轴自动选择侧向主视图 |
| 直腰槽 | 两个半圆柱端面、相同半径/方向、共同的两个侧壁；读取宽度与总长 |
| 同轴阶梯孔候选 | 同一实体的共轴线、不同直径圆柱段；报告候选，不自动赋予沉孔/沉头/螺纹语义 |
| 圆锥、局部内外圆弧 | 报告几何类别；不把任意圆锥面直接认定为沉头孔 |
| 原生特征 | 分类 Hole Wizard、倒角、圆角、阵列/镜像、切除、旋转、钣金、螺纹特征及导入实体；不从底孔直径猜 M 规格 |
| 零件类别 | 板、轴、棱柱、多实体、装配体和钣金，用于出图策略与报告 |

以上几何识别与原生特征名称分类是两类证据。识别不会自动证明所有加工尺寸已标注。报告中的 `linked_size_dimension` 需要原生实体引用及数值共同吻合；无法直接关联的条目继续要求复核。阶梯孔按圆柱段记录，数量不能直接代替物理孔的加工数量。非轴对齐、分割圆柱面、交叉孔和复杂槽可能保守识别为局部面或未知范围。

新增流程：

- **自动主视图**：优先让孔槽正对观察方向，再比较投影面积；可关闭。其他正投影视图由主视图派生，保持原生投影关系。
- **全部配置**：清空指定配置后启用，逐配置生成独立工程图。读取对应配置真实几何，完成后恢复原配置，不保存模型。宿主切换配置可能更新模型的保存标志。
- **队列**：扫描文件夹（排除锁文件与链接目录）、加入装配体未压缩组件、路径去重、任务进度、失败件重试、批次 JSON 总结。组件按所选/当前配置出图，不自动继承每个装配实例的引用配置；虚拟组件须先保存。
- **布局**：标题栏预留高度可调；保留原生尺寸分层，将纸外文字重新放回可打印区域，避免挤到同一视图区边界。该移动不改变尺寸测量关联，最终仍检查 PDF 碰撞。
- **中心标记**：首次保存后插入并回读真实中心标记，保存重开再次校验数量；当前启用圆孔标记，槽中心标记尚未完成验收。
- **PDF 文字审查**：可直接勾选，需系统可调用 `python` 且安装 PyMuPDF。全局一对一匹配避免多个相同数值抢占同一个 PDF 文字；支持 R/Φ/Ø/角度数字，缺失或碰撞写回任务警告。未安装依赖时保留图纸并报告原因。
- **性能与诊断**：每阶段耗时、自动标注前后尺寸数、重试次数、识别证据、实际选项和版本全部写入报告；实体引用以 SHA-256 摘要关联，缩小报告体积。仅在完全没有新增尺寸时尝试一次备用标注参数。

## 快速使用

1. 安装 x64 SolidWorks 与 .NET Framework 4.8。编译需要 .NET SDK 和 .NET Framework 4.8 targeting pack。本机已编译通过。
2. 在本目录 PowerShell 运行 `./build.ps1`。其他安装目录使用 `./build.ps1 -SolidWorksDir 'D:\...\SOLIDWORKS'`。
3. **管理员 PowerShell** 运行 `./install.ps1`。写入 COM 与 SolidWorks 插件注册项需要管理员权限。注册不自动加载，也不默认设置开机启动。
4. SolidWorks → 工具 → 插件 → 勾选 **AutoDrawing 自动出图**。通过工具菜单中的 **自动出图 → 批量出图** 打开窗口。
5. 添加已经保存的 `.sldprt` / `.sldasm`，选择空视图、单页 `.drwdot` 模板及输出目录，点击开始。GB/T 模板选第一角；第三角必须使用相应的自定义模板和投影符号。
6. 查看输出 `.slddrw`、`.pdf` 和 `.report.json`，完成制造审核。可选导出 `.dxf`。

直接使用 `release/AutoDrawing` 时，可运行免注册启动器；也可在该文件夹运行管理员 `./install.ps1` 集成菜单，无需重新编译。安装后保持 DLL 文件夹位置不变。升级前先在 SolidWorks 中卸载插件/退出 SolidWorks，替换后重新注册。

卸载：管理员执行 `./install.ps1 -Uninstall`，仅取消本插件注册，不删除图纸及源码。

## 去重和布局优化

- 模型尺寸：必须具有相同模型、配置、参数完整名、持久引用及标注语义。相同数值本身不构成删除理由。
- 几何整体尺寸：仅对单实体零件、当前活动配置、无公差和无自定义文字的线性参考尺寸启用。读取真实模型参考点及尺寸方向，确认尺寸跨越同一实体某一模型轴的两个包围盒边界后，才允许跨视图去重。
- 多实体、装配体几何参考尺寸、局部孔距及身份不明确的尺寸保守保留。已有孔数量/直径标注不按整体线性尺寸处理。
- 删除工程图显示尺寸后重建，再检查是否复活；不删除三维驱动参数。悬空标注保留并报告，避免误删尺寸基准。
- 按实际视图边界选择统一标准比例，图纸比例与视图比例一致，预留边框、标注通道及底部 65 mm 标题栏区域。实际模板标题栏更大时仍需调整。
- 第一角：俯视图置下，左视图置右；第三角：俯视图置上，右视图置右。支持中英文标准视图名称。
- 批处理串行运行在 UI STA 线程，不把 COM 对象送入后台线程；任务间允许停止。每件独立失败，输出名称含时间与随机短 ID，不覆盖原文件。

本机 `IDrawingDoc.AutoDimension` 实际生成尺寸，但返回 `1 / swAutodimStatusBadOptionValue`，与官方成功枚举 `0` 不一致。独立参数矩阵确认此现象持续存在；日志保留返回码并记录实际新增数量。导入模型尺寸的数量取决于模型中是否有可导入的尺寸。坐标尺寸、装配体细节和其他 SolidWorks 年份仍未完成真机回归。

**倒角数量合并是默认关闭的试验功能**：只接受同一倒角特征、等距 45°、全部为平面的多面倒角，在关联线性尺寸前添加 `n X C`；不合并独立特征、不删除其他倒角尺寸。此路径尚未真机回归，输出数量必须复核。复杂倒角、不同角度、曲面倒角均保留并报告。

每个工程图返回 `review_required`，不是无人值守制造放行：孔槽覆盖、完整尺寸链、公差、标题栏内容、引线交叉、图幅外标注、剖视和 GD&T 仍需专业审核。当前不自动填写标题栏业务字段，不承诺图片中任意模型的一键完整制造图，也不将普通文字当作原生孔表/BOM/GD&T。未实现 BOM、剖视、局部视图和钣金展开。

## 测试与 PDF 审查

```powershell
./test.ps1
./smoke.ps1 -Model 'D:\零件\板.SLDPRT' -Template 'D:\模板\A3.drwdot'
python scripts/review_pdf.py 'D:\输出\某件.report.json'
```

真机测试会使用已运行的 SolidWorks，必要时启动实例；原模型只读打开，不保存、不主动关闭用户原来打开的文档。新建工程图失败时留在会话中方便检查。输出中间报告和审查证据置于 `artifacts/`。

PDF 审查需要 `pip install pymupdf`；插件运行本身不需要 Python。脚本输出每页 PNG 和独立 `.pdf-review.json`，按 SI 数值转 mm/角度、COM 标注坐标及 PDF 向量文字框逐一寻找候选，未匹配则明确记录。只覆盖简单数字标注；孔表、分数、双单位、公差及引线等需人工核查，关联本身不代表尺寸语义完整。

## 源码

- `src/AutoDrawing/Addin.cs`：SolidWorks COM 插件入口与菜单回调。

- `DrawingEngine.cs`：原生视图、标注、去重、倒角试验、导出、保存重开验证。
- `Planning.cs`：参数验证、图纸布局、去重规则、结构化证据。
- `Recognition.cs`：BRep 几何与原生特征分类、孔组、主视图选择、尺寸关联检查。
- `Batch.cs`：文件发现、配置展开、任务隔离和批次总结。
- `PdfAudit.cs`：可选 PDF 审查子进程，超时与失败报告。
- `Launcher.cs`：免注册桌面启动入口。
- `tests/`：规则测试、同一执行引擎的真机测试；夹具生成需本机 SolidWorks 自动化技能。
- `scripts/review_pdf.py`：独立 PDF 文字审查和预览。
- `docs/research.md`：图片研究、技术证据及改进路线。
